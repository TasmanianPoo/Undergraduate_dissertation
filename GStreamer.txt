Solution:

The PsychToolbox library file (psychtoolbox-3.0.19.13.mltbx) has been made available on the University’s classroom share:  \\cfs\shared\class\MATLAB\ (or if on the teaching PCs, drive L:\)

 

The toolbox needs to be installed at the start of every user/student session.  The easiest way to do this is to include the following lines of code in a file called startup.m and getting the students to put it their Documents\MATLAB folder.  This will automatically run every time MATLAB is launched.   Alternatively, the code can be included at the start of any MATLAB script that is requiring the psychtoolbox functions.

 

if not(exist('PsychStartup', 'file'))

    matlab.addons.toolbox.installToolbox('\\cfs\shared\class\MATLAB\psychtoolbox-3.0.19.13.mltbx')

end

psychbasicpath=fullfile(PsychtoolboxRoot,'PsychBasic')

rmpath(psychbasicpath)

addpath(psychbasicpath,'-end')
